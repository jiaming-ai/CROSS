Summary

CROSS maps a place once and finds its way back into that map in every later session: at night, across seasons, after the furniture moved, or with another camera. It treats every visual match as a pose hypothesis and commits only what the robot's own motion confirms, so a single look-alike view cannot corrupt the map. RGB-D, stereo or monocular; with wheel odometry, a VIO, an IMU or none.

Overview

Best multi-session relocalization

Start anywhere in a map from another session, at night, in snow, in a crowd or with the lights off, and CROSS finds where it is. The best visual multi-session relocalization in our benchmark →

Accurate tracking, any sensor setup

Accurate tracking with RGB-D, stereo or one camera, with wheel odometry, a VIO, an IMU or nothing at all: ready-made modes, picked with one flag.

Large scale, with or without GPS

Sessions of kilometers, indoors and out, kept accurate by verified loop closures with or without GPS; with it, the map is placed on the Earth. Soon, several robots will build one map together.

Light on the robot, heavy in the cloud

The robot needs under half a CPU core: it runs its odometry and sends about one frame in five to a GPU server, which does the heavy work and keeps it localized with 100 ms of added network delay. A map made with one camera also serves another camera. Remote sessions →

Chapters5:09

Method

Place recognition alone confuses look-alike places, and one false loop closure can ruin a map. CROSS keeps competing answers alive and lets the robot's own motion decide between them.

  1. 01

    Remember places

    The map is a graph of keyframes, images with their poses, linked by odometry and by verified loop closures. It is saved to disk and loaded in every later session.

  2. 02

    Hypothesize poses

    Place recognition retrieves keyframes that look alike. One pass of a multi-view model, or PnP on depth, turns each into a metric pose. Competing poses live side by side in a Gaussian mixture on SE(3).

  3. 03

    Let odometry decide

    As the robot moves, hypotheses that disagree with its odometry lose weight and die out. A new session joins the map only when its placement holds over several steps and places.

  4. 04

    Commit what holds

    A loop closure enters the map only after statistical consistency tests; pose-graph optimization then removes the drift that built up in between.

Get started

Linux, NVIDIA GPU, about 10 GB

One script installs everything into a local environment and downloads the models. Then map a session, save it, and relocalize the next session in it.

  • ReadsRGB-D and stereo folders, KITTI raw, TartanAir, Virtual KITTI 2, OpenLORIS, iPhone recordings (Record3D); TUM RGB-D after conversion
  • Install--stereo covers the RGB-D and VGGT-Omega modes; --mono adds DPVO and the monocular IMU modes
  • Pythonfeed frames, read poses in the map's coordinates
  • Robota robot without a GPU runs cross-edge, a client without PyTorch, and a GPU server does the rest: remote sessions
  • LicenseMIT-licensed code. The learned models (VGGT-Omega, Depth Anything 3) are for non-commercial research; the RGB-D modes with PnP use neither

Terminal

  1. # install: a local .venv with PyTorch, CROSS and the models
  2. $ git clone https://github.com/jiaming-ai/CROSS.git && cd CROSS
  3. $ bash install.sh --stereo && source .venv/bin/activate
  5. # two recordings of one office (OpenLORIS-Scene from Hugging Face, 10.6 GB)
  6. $ PATH="$HOME/.local/bin:$PATH" uv pip install py7zr
  7. $ bash benchmark/datasets/download_openloris.sh data/openloris office1-1_7
  8. $ python scripts/datasets/convert_openloris.py \
  9. data/openloris/office1-1 data/posed/office1-1
  10. $ python scripts/datasets/convert_openloris.py \
  11. data/openloris/office1-2 data/posed/office1-2
  13. # session 1: build a map and save it
  14. $ python run.py data/posed/office1-1 --mode rgbd_wheel \
  15. --save-map maps/office/map.pkl
  17. # session 2: relocalize in it, write poses in the map frame
  18. $ python run.py data/posed/office1-2 --mode rgbd_wheel \
  19. --load-map maps/office/map.pkl --save-poses office1-2.txt
